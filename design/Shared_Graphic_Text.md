# Shared outlined game lettering

Use UIKit.graphic_label(text, size_px, UIKit.GraphicText.WHITE).
Color variants: WHITE, GOLD, GREEN, PINK, RED.

Uses the shared title FontVariation, warm brown outline and subtle downward shadow. Supports live text/numbers and localization without separate generated glyph images. Labels remain editable; no bitmap-font atlas is needed for these counters. Existing generated decorative headings remain artwork.

Order count now uses WHITE, aligned at the bottom-right of each kuih, with no round background. Counts still update/pop and switch to the existing green completion tick. RemainingCountBadge is now a transparent Control; OrderCount remains its child for existing scene naming/tools.
