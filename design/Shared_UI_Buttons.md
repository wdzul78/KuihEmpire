# Shared game UI

English is the default for new saves. Legacy MVP saves adopt English once through language_policy 2, preserving progress. Subsequent selections in Settings remain saved.

Resource bars share ResourceBarArt, a common body height, icon scale and 36px label size. Home and gameplay use equal heart/coin/star widths and aligned rows.

GameButton provides primary green, secondary pink, tertiary orange/brown and danger red styles. ButtonArt preserves rounded end proportions and stretches the middle only. Settings controls use 112px height and 38px button captions. Toggles retain their distinct switch artwork.

## Final orange prompt

Use case: stylized-concept. Asset: reusable blank UI button for Kuih Empire tropical cartoon mobile game. Generate one long horizontal pill button, front view, landscape 5:1 proportion, isolated on actual transparent alpha background. Smooth glossy face, softly rounded semicircular ends, narrow cream inner rim, gold wooden bevel and dark brown clean outer outline. Subtle tiny tropical leaf silhouettes at far left and right only; big clear plain centre for text added by the game. Tasteful bright glint top left and restrained lower shading, polished friendly 2D hand-painted sprite. Whole button fills canvas with small safe transparent margins. No text, symbols, icons, letters, watermark, cast shadow, no background. One button only. Colour: warm burnt orange and honey brown face, golden caramel highlight. Designed as tertiary Back/Home button, clearly distinct from green and pink.
