# Fredoka for Kuih Empire

Source: https://github.com/google/fonts/tree/main/ofl/fredoka
License: SIL Open Font License, included in OFL.txt.
Variable font axes: weight 300–700, width 75–125.
UIKit sets weight 600 for controls and 700 for titles, width 100.
The original Candy atlas remains available for decorative bitmap lettering.
