# Directional Tapau v3

Mode: built-in imagegen edits, transparent PNG output. Previous directional_v2 images are preserved. BoardArt uses these new sprites. No special rules or animation timings changed.

- `tapau_horizontal.png`: kraft/pandan package with enlarged front badge and bold green left/right arrow.
- `tapau_vertical_blue.png`: silver tiffin with dominant cyan/blue up/down arrow and thick white/navy borders.

Verified with rendered Godot gameplay previews at both 8x8 and 10x10 board dimensions. Existing vertical slot sizing and positioning are retained.

## Horizontal prompt

Reference: `assets/specials/directional_v2/tapau_horizontal.png`.

Make the front cream badge substantially larger, nearly filling the front face, facing the viewer more directly. Put a very large simple horizontal LEFT-RIGHT double-headed arrow on it: broad shaft, huge unmistakable triangular arrowheads, saturated pandan green fill, thick cream-white inner border and very thick dark forest green outer outline. Arrow occupies most of the badge, visually dominant over every decorative detail. Simplify small decorations near the badge. Keep a compact centered square icon, transparent background, no text, no extra objects, no external glow or particles. Horizontal arrow only, never vertical.
